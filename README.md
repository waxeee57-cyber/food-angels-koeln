# Food Angels Köln

Image-led Demo-Website für ein Ehrenfelder Restaurant: Smash-Burger, Schupfnudeln, Salate. Deutsch. Besuch, Abholung, Catering.

## Lokal starten

```bash
npm install
npm run dev
```

```bash
npm run build
npm start -- --port 4317
```

## Seiten

- `/` — Hero, CTAs Besuchen / Abholung / Catering, Fotogrid
- `/speisekarte` — Burger, Schupfnudeln, Salate
- `/abholung` — Takeaway
- `/catering` — Pakete + Anfrageformular (Demo, kein Versand)
- `/kontakt` — Adresse, Zeiten, Karte (Ehrenfeld, Platzhalter)
- `/impressum` · `/datenschutz`

Next.js 16, TypeScript, Tailwind CSS 4, shadcn/ui. Demo: keine echten Bestellungen.
